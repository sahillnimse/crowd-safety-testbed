# opencv-python, NOT opencv-python-headless.  Two scripts open a window —
# calibrate_ground_plane.py and run_flow_analysis.py (--show) — and
# on a headless build cv2.namedWindow raises
#
#     error: (-2:Unspecified error) The function is not implemented.
#            Rebuild the library with Windows, GTK+ 2.x or Cocoa support
#
# which is fatal rather than degraded: calibrate_ground_plane.py is how a
# camera gets its homography, so a headless install silently makes speed in
# m/s and Helbing crowd pressure unreachable.
#
# The trap is that easyocr depends on opencv-python-headless, so a plain
# `pip install -r requirements.txt` installs BOTH.  They unpack into the same
# cv2/ directory and whichever lands last wins, so the working build can be
# replaced by the headless one at any time with no error and no warning.  If
# a GUI script starts failing, this is why:
#
#     pip uninstall -y opencv-python opencv-python-headless opencv-contrib-python
#     pip install opencv-python==5.0.0.93
#
# Check with:  python -c "import cv2; print(cv2.getBuildInformation())" | findstr GUI
# It must say WIN32UI (or GTK/Cocoa), not NONE.

# `pip install torch torchvision` from this file alone can silently install

# still "work" — just 10-50x slower with no error. On a machine with an
# NVIDIA GPU, install torch FIRST and SEPARATELY from the CUDA index:

#   pip uninstall -y torch torchvision   # if already installed

#   # (swap cu121 for your driver's CUDA version — check `nvidia-smi`)
